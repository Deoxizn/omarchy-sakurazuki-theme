# Sakurazuki

Dark low-contrast Omarchy theme built around a sakura wallpaper.

Compatible with the current Omarchy Quattro release (Quickshell-based shell).

## Installation

```bash
omarchy-theme-install https://github.com/ahmed-z0/omarchy-sakurazuki-theme.git
```

## What's included

- `colors.toml` — semantic palette (source of truth; drives the Quickshell bar,
  menus, popups, notifications, lock screen, and all generated app themes)
- `shell.lock.toml` — lock screen colors
- `hyprland_active_border` / `hyprland_inactive_border` — active-window border
  gradient (rose → moonlit plum)
- `backgrounds/sakura.png` — wallpaper
- `alacritty.toml`, `btop.theme`, `chromium.theme`, `ghostty.conf`,
  `kitty.conf` — app palettes
- `neovim.lua` — aether.nvim (v3) colorscheme
- `icons.theme`, `vencord.theme.css`, `warp.yaml` — misc app themes
- `preview.png` — theme switcher preview

## Palette

Near-black plum base, muted rose accents, moonlit blue highlights.

| Role  | Color    |
|-------|----------|
| bg    | `#14111A` |
| fg    | `#D8D0DC` |
| accent| `#B6849D` |
| muted | `#6B5E72` |
